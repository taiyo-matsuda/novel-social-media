# 0009 チャット形式・ライトノベル調にせず、文芸として読める長編を書かせる

2026-11-07

## 決めたこと

- Ballad の小説は「ちゃんとした小説」（文芸として読める文章・長編）にする。チャット形式の読む画面や、ライトノベル・ネット小説の定型は採らない。基準は [writing-standard.md](../writing-standard.md)。
- 章を生成するたびに、AI が読者に見せない創作メモ（人物・あらすじ・伏線・見通し）を書き、次の章ではメモと直近2章だけを渡す（`works.story_notes`）。
- 章の生成は effort を medium から high に上げる（構成と一貫性を考える余地を取る。料金と待ち時間は増える）。
- 最初の画面の冒頭文から、ライトノベル調の4つ（元四天王のパン屋、悪役令嬢、しゃべる猫、竜の世話係）を外し、文芸寄りの5つを足した。外したものは `openings.retired = 1` にして、過去の答えは好みとして残す。

## 理由

- 作者（taiyo さん）の方向：チャット形式の画面やライトノベル調には違和感があり、文芸として読める小説で溢れるアプリにしたい。
- 改善前のプロンプトは文体の指示がなく、「続きが読みたくなる章」という指示だけだったため、会話の多い軽い文章や、毎章の無理な引きになりやすかった。
- 前の章を全部渡す方式は、長編になるほどプロンプトが伸び、人物や伏線が埋もれる。

## まだ決めていないこと
