# 0005 Google でログインできるようにする

- 日付：2026-10-27
- 状態：決定

## 決定

- ログインの主な方法を **Google** にする。ログイン画面は「Googleで続ける」を一番上に置き、メールアドレス＋パスワードは「メールアドレスで続ける」から使えるように残す
- アプリ（Flutter）は `google_sign_in` で端末上で Google にログインし、受け取った **ID トークン**をサーバーの `POST /api/auth/sign-in/social`（Better Auth）に送る。サーバーは Google の署名と宛先（クライアントID）を確かめ、ログイン状態のトークン（bearer）を返す
- Google Cloud の OAuth クライアントIDは「Web（サーバーが確かめる宛先）」「iOS」「Android」を作り、サーバーの `GOOGLE_CLIENT_IDS` に全部入れる。クライアントIDは秘密ではない

## 理由

- taiyo が「メールログインではなく Google OAuth を使いたい」と決めた
- ID トークン方式なら、ブラウザへの転送やリダイレクトURLがいらず、スマホアプリから素直に使える

## 注意

- **App Store に出すときは「Appleでサインイン」も必要になる見込み。** Google など他社のログインを入れるアプリは、同等のプライバシー配慮があるログイン（Apple が代表例）も用意するよう審査ガイドライン 4.8 で求められている
- メールアドレス＋パスワードを残したのは、Google を使わない人と、すでに登録したテスト用アカウントのため。不要になったら画面から外す
- Web 版を作るときは、ブラウザ向けの転送型ログイン（`GOOGLE_CLIENT_SECRET` とリダイレクトURL）を足す
