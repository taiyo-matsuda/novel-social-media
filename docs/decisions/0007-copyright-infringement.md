# 0007 無断転載への備え：AIなしの投稿を認め、画像のアップロードは受け付けない

- 日付：2026-11-06
- 状態：決定（通報・取り下げの流れは実装済み。AIなしの投稿はこれから）

## 背景

- 同じ種類の小説アプリ（テラーノベル）は2022年に無断転載で炎上した。中心は小説本文ではなく、表紙（サムネイル）や作者アイコンへの他人のイラスト・アニメのスクリーンショット・芸能人の写真の無断使用だった（[ITmedia](https://www.itmedia.co.jp/news/articles/2207/19/news119.html)、[J-CAST](https://www.j-cast.com/2022/07/19442031.html?p=all)）
- いまの Ballad は、本文をサーバーのAI生成（`POST /api/chapters`）でしか作れず、画像も上げられない

## 決定

- **AIを使わずに自分で書いた小説も投稿できるようにする**（MVPの後に作る）。`works.ai_generated` で区別する
- **表紙とアイコンに画像のアップロードは受け付けない。** 表紙はAIで作るか、用意したデザインから選ぶ。アイコンは Google のプロフィール画像か、用意したものから選ぶ
- 本文を貼れるようになると盗用の入口は開くが、テラーノベルでも本文の盗用は大きな問題になっておらず、小説を書く人は本文の盗用を避ける傾向があると見る。**手書きの投稿は、まず通報と取り下げの仕組みだけで始める**
  - 公開作品同士の類似チェック（言い換えも拾えるよう、文章の意味の近さで比べる）は、本文の盗用の通報が目立ってきたら入れる
  - AIが書いた章を直せるようにする場合は、AIの元の文章と編集の記録を残す（後から盗用を確かめる材料になる）
- 見抜けない盗用（他サイトの作品の言い換えなど）は、通報と取り下げを速くして抑える
  - 通報が来たら運営に即通知する。権利侵害の通報は分けて目立たせる
  - **権利侵害の通報は1件、それ以外は3件**たまった作品は、確認の前に仮で一覧から外す。作者に知らせ、異議を出せるようにする
  - 取り下げを記録し、**3回**でアカウントを停止する。止めたアカウントはログインできず、公開作品も出ない
  - 本文のコピーは制限しない
  - アプリを使っていない権利者がWebから申し立てられる窓口を置く
- 盗作をめぐる恨みを生まないようにする
  - アイデア・設定・ありがちな展開の類似は違反にしない。文章や具体的な表現の盗用だけを対象にし、規約で公開する
  - 通知は「規約に基づき非公開にしました。異議はこちら」とだけ伝え、相手を責めない
  - 通報した人を相手に見せない。対応は「Ballad運営」として行い、担当者の名前を出さない

## まだ決めていないこと

- 公開前に弁護士に、規約の線引きと脅迫などへの対応を相談する

## 実装（2026-11-06）

- 決まりの数は `apps/api/src/features/moderation/policy.ts` にある
- 作品の状態は `works.moderation`（ok／hidden／removed）。作者の公開・下書きとは別に持ち、ok 以外は他人に見せない
- 運営の管理画面は `/admin`。運営アカウント（メールアドレス＋パスワード）でログインし、そのアカウントの役割（`user.role`）が `admin` のときだけ使える（2026-11-07 に合言葉から変更し、同日に利用者IDの一覧のシークレットからアカウントの役割に変更。役割は登録の API からは変えられず、運営が DB を直接書き換えて付ける）。通報・異議のある作品と、仮で隠した作品が並ぶ。「問題なしに戻す」「仮で非表示」「取り下げる（違反1回）」「停止を解く」ができる。問題なしに戻すと、取り下げの違反も取り消す
- 権利者の申し立ては `/rights`（ログイン不要）。運営が管理画面で作品IDに結びつけ、取り下げると対応済みになる
- 通報・異議・申し立て・停止は `OPS_WEBHOOK_URL`（Slack）に即知らせる。通知には通報者・申立人の名前や連絡先を載せない
- 退会したアカウントは停止の記録も消えるので、同じメールアドレスで登録し直せる。目立つようなら、止めたメールアドレスを別に残す
- 申し立てフォームには機械的な投稿を弾く見えない欄だけを置いている。迷惑な投稿が増えたら Cloudflare Turnstile を足す
