# 0001 技術スタック

- 日付：2026-10-26
- 状態：提案（taiyo の確認待ち）

## 決定

Web先行で、Next.js + TypeScript + Supabase + Claude API で作る。スマホは当面ブラウザで対応する。

## 理由

- MVPを最速で出すため、1つのコードベースで画面とサーバーを書ける構成にした
- アプリ内課金の手数料（15〜30%）が関わるのは課金開始後なので、ネイティブアプリ化はフェーズ2で判断する
- AIエージェントが扱いやすい、情報の多い構成を選んだ

## 代わりに検討したもの

- Expo（React Native）でアプリ先行：審査と手数料が早い段階から関わる
- Web とアプリのモノレポ：最初の構成が重い
