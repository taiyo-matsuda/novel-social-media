# プロダクト概要とMVP範囲

元の構想メモ：<https://claude.ai/artifact/AUQ3PHLPSQJbHoP5rSEbEW>

## コンセプト

「読みたいものを読み尽くした読者」が、AIに自分専用の小説を書いてもらえるアプリ「Tsuzuri」。読者が自分用に生成した作品を公開すると、そのまま作者になる。**スマホアプリ（iOS / Android）として提供する。**

## MVP（無料）

1. **好み入力**：短い冒頭文をいくつか見せ、「読みたい／読みたくない」を選ぶ
2. **AI生成**：好みから第1章を生成。章ごとに展開リクエストを出して続きを生成
3. **公開**：生成した作品を公開する
4. **ランキング閲覧**：他人の公開作品をランキングから読む（本文はログイン必須）
5. **行動学習**：評価・読了率・離脱位置を記録し、次の生成に反映する

## MVPでやらないこと

- コイン・有料閲覧・作者への送金（フェーズ2以降。アプリ内課金の手数料15〜30%を分配率に反映する）
- AI機能の課金（フェーズ2以降）
- 翻訳、漫画SNSとの連携
- Web版の画面（作品紹介ページなどは必要になったら別途作る）

## 未決事項（実装で影響するもの）

- AI生成作品と人間の作品をランキングで分けるか、表示で区別するか（`works.ai_generated` だけ先に持っている）
- ランキングの重み（`packages/core/src/ranking/score.ts` は仮置き）
- 最初から多言語にするか
